Playlist Maker — это мобильное приложение для создания и управления музыкальными плейлистами. Пользователь может формировать собственные подборки, добавлять треки, менять обложки, а также сохранять понравившиеся песни в избранное.

Описание экранов и функциональности:

Главный экран:
Содержит навигационное меню с иконками, позволяющее перейти в любой раздел приложения. Переходы реализованы через NavController для плавной навигации.

Поиск музыки:
В разделе поиска доступна строка ввода с историей предыдущих запросов. Экран поддерживает несколько состояний: первоначальный экран с предложением начать поиск, отображение индикатора загрузки, вывод найденных треков при успешном запросе, сообщение об отсутствии результатов и уведомление о сетевой ошибке. Управление логикой выполнено через ViewModel, где также сохраняется история поиска.

Настройки:
Пользователь может включить тёмную тему с помощью анимированного переключателя, поделиться информацией о приложении, отправить отзыв разработчикам и открыть пользовательское соглашение.

Плейлисты:
Приложение позволяет создавать собственные плейлисты, задавать названия и описания, выбирать изображение из галереи в качестве обложки. Реализована возможность объединения нескольких плейлистов. В подробной информации отображаются список треков и общее время воспроизведения.

Избранное:
Пользователь может сохранять любимые треки в отдельном разделе.

Детали трека:
На экране информации о треке показываются расширенные данные. Отсюда можно добавить трек в плейлист или в избранное.

Технологии:
Android Studio Otter, версия 2025.2.1
Используемая версия SDK: Android API 36
